## 1.1.0

- **Breaking:** Raised the minimum SDK to Dart 3.11 / Flutter 3.41. This is required
  by the migration off the deprecated `showCupertinoSheet(builder:)` parameter.
- Migrated `showCupertinoSheet` from the deprecated `builder` parameter to
  `scrollableBuilder`.
- Material tab: added Progress Indicators, Menus (`MenuAnchor`, `DropdownMenu`,
  `PopupMenuButton`), Dialogs & Notifications (`AlertDialog`, `SnackBar`) and
  Badges & Tooltips sections.
- Cupertino tab: added Activity Indicators (including
  `CupertinoLinearActivityIndicator`), Dialogs, Pickers and Context Menu sections.
- Regenerated the screenshots on Flutter 3.44. Flutter 3.41 updated
  `material_color_utilities` to 0.13.0, which changes the colors generated by
  `ColorScheme.fromSeed`, so the previous screenshots no longer matched what the
  inspector renders.
- Documented the bundled agent skill in the README.
- Replaced the placeholder library-level documentation.
- Removed the unused `test` dev dependency.
- Excluded the demo GIF and tests from the published archive, reducing the download
  from 5.6 MB to under 1 MB.
- Added a CI workflow running format, analyze, test and publish validation.
- Fixed a test that had been failing since 1.0.2.
